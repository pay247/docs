---
title: '代付订单回调'
---

### 通知URL

仅在创建订单时提供 `notify_url` 且订单进入终态后发送 `POST` JSON。商户应验证签名、按订单号幂等处理，并返回纯文本 `SUCCESS` 或 `OK`（忽略大小写和首尾空白）；其他响应会触发重试。`receipt` 在查询接口中可为完整 URL，在回调中是保存的原始值。

| 参数 | 是否出现 | 类型 | 说明 |
|---|---|---|---|
| `mch_id` | 始终 | string | 商户号，标识该订单所属商户 |
| `mch_order_no` | 始终 | string | 商户提交的订单号 |
| `order_no` | 始终 | string | Pay247 生成的平台订单号 |
| `currency` | 始终 | string | 订单币种 |
| `pay_method` | 始终 | string | 实际支付方式代码 |
| `amount` | 始终 | string | 订单金额，以订单币种计 |
| `fee` | 始终 | string | 订单手续费，以订单币种计 |
| `status` | 始终 | string | SUCCESS 或 FAIL；冲正映射为 FAIL |
| `receipt` | 始终 | string | 交易凭证路径/内容，可能为空 |
| `paid_at` | 始终 | integer | 完成时间，毫秒时间戳；没有时为 0 |
| `created_at` | 始终 | integer | 创建时间，毫秒时间戳 |
| `error` | 始终 | string | 错误信息，可能为空 |
| `utr` | 条件性 | string | 仅非 FAIL 的 INR 订单返回，值可能为空 |
| `sign` | 始终 | string | 回调签名 |

```json
{
  "mch_id": "MCH12345678",
  "order_no": "PO202609280001",
  "mch_order_no": "PAYOUT-1001",
  "currency": "INR",
  "pay_method": "BANK",
  "amount": "100.00",
  "fee": "2.00",
  "status": "SUCCESS",
  "receipt": "",
  "paid_at": 1693233354134,
  "created_at": 1693233334134,
  "error": "",
  "utr": "123456789012",
  "sign": "<computed signature>"
}
```

### 通知回调响应结果

商户应返回 `Content-Type: text/plain` 的响应正文：

| 返回内容 | 处理结果 |
|---|---|
| `SUCCESS` 或 `OK` | 确认通知，停止重试；大小写及前后空白不影响判断。 |
| `FAIL` 或其他内容 | 视为未确认，网关按递增间隔重试，当前任务最多尝试 8 次；最终状态仍应通过订单查询核对。 |
