## 2026-11-12

### 补充代收退款状态说明

- [查询代收订单](/api-reference/cn/payin_query#退款状态)：明确 `data.status = REFUND` 表示已退款，补充状态说明及查询响应示例。
- [代收订单回调](/api-reference/cn/payin_notify#退款状态)：在 `status` 的取值说明中补充 `REFUND`（已退款），新增退款通知示例，并说明支付成功后的退款状态变化及重复通知的幂等处理。
- 退款状态沿用现有 `status` 字段，无新增请求参数或响应字段；`amount` 和 `fee` 仍表示原订单金额和订单手续费，不表示实际退款金额。
- 新增本页面及导航入口，后续 API 文档修改按日期倒序记录。
