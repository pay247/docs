### Notify URL

If `notify_url` was supplied at creation, the gateway sends `POST` JSON after a final status. Verify the signature, handle the order idempotently, and return plain text `SUCCESS` or `OK` (case and surrounding whitespace are ignored); other responses trigger retries. `receipt` may be a full URL in query responses but is the stored raw value in callbacks.

| Field | Present | Type | Description |
|---|---|---|---|
| `mch_id` | Always | string | Merchant ID that owns the order |
| `mch_order_no` | Always | string | Order number supplied by the merchant |
| `order_no` | Always | string | Platform order number generated by Pay247 |
| `currency` | Always | string | Order currency |
| `pay_method` | Always | string | Selected payment method code |
| `amount` | Always | string | Order amount in the order currency |
| `fee` | Always | string | Order fee in the order currency |
| `status` | Always | string | SUCCESS or FAIL; reversal maps to FAIL |
| `receipt` | Always | string | Receipt path/content; may be empty |
| `paid_at` | Always | integer | Resolution time in milliseconds; 0 if unavailable |
| `created_at` | Always | integer | Created time in milliseconds |
| `error` | Always | string | Error; may be empty |
| `utr` | Conditional | string | Only for non-FAIL INR orders; may be empty |
| `sign` | Always | string | Callback signature |

```json
{
  "mch_id": "MCH12345678",
  "order_no": "PO202609280001",
  "mch_order_no": "PAYOUT-1001",
  "currency": "INR",
  "pay_method": "BANK",
  "amount": "100.00",
  "fee": "2.00",
  "status": "SUCCESS",
  "receipt": "",
  "paid_at": 1693233354134,
  "created_at": 1693233334134,
  "error": "",
  "utr": "123456789012",
  "sign": "<computed signature>"
}
```

### Callback response

Return a `Content-Type: text/plain` response body:

| Response body | Result |
|---|---|
| `SUCCESS` or `OK` | Acknowledged; retries stop. Case and surrounding whitespace are ignored. |
| `FAIL` or anything else | Unacknowledged; the gateway retries with increasing delay, up to eight total attempts in the current job. Reconcile final status with the query API. |

The original “five retries at 3/9/27/81/243 seconds” no longer matches the gateway job and has been corrected here.
